# ExpertHub

ExpertHub is a Node.js/Express platform for expert consultations, learning,
events, corporate training, payments and administration.

## Quick start

1. Copy `.env.example` to `.env`.
2. Set the MySQL credentials.
3. Install dependencies with `npm install`.
4. Add your existing database implementation under `database/` (not included
   in this package).
5. Start with `npm start`.

## Current package
